description: 김비서-데이터 폴더를 읽고 dashboard.html을 업데이트한 뒤 오늘의 업무 브리핑을 출력한다
---

지금부터 비서 모드로 아래 3단계를 순서대로 실행해줘.

---

## STEP 1 — 데이터 읽기

`김비서-데이터/` 폴더의 파일 5개를 모두 읽어줘:
- `업무목록.csv` — 할 일, 우선순위, 상태, 담당자, 마감일
- `주간일정.txt` — 이번 주 일정
- `프로젝트현황.csv` — 프로젝트 진행률
- `매출데이터.csv` — 매출 데이터
- `회의록.txt` — 최근 회의 내용

---

## STEP 2 — dashboard.html 업데이트

읽은 데이터를 바탕으로 `dashboard.html` 안의 JavaScript 데이터를 최신 상태로 동기화해줘.

업데이트 대상:
1. **tasks 배열** — 업무목록.csv의 내용과 일치하도록 (완료된 항목은 `status: '완료'`, 나머지는 상태 그대로 반영)
2. **daily 배열 (선 그래프)** — 매출데이터.csv 기준 일별 합계 재계산
3. **products 배열 (막대 그래프)** — 매출데이터.csv 기준 제품별 누계 재계산
4. **프로젝트 목록** — 프로젝트현황.csv의 진행률·상태·담당자 반영
5. **할 일 카운트 뱃지** — 실제 tasks 개수로 업데이트 (`11개` 등)

변경한 부분을 간단히 요약해줘.

---

## STEP 3 — 오늘의 브리핑

오늘 날짜 기준으로 아래 형식으로 브리핑을 출력해줘.
마감이 지난 항목은 ⚠️ 로 표시하고, 오늘/내일 마감은 🔥 로 강조해줘.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🤵 김비서 데일리 브리핑 — [오늘 날짜]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📅 오늘의 일정
  [오늘 날짜에 해당하는 일정 목록, 없으면 "일정 없음"]

✅ 우선순위 높은 할 일 (마감순)
  [상태가 '완료'가 아닌 높음 우선순위 항목, 마감 가까운 순]

📋 전체 업무 현황
  - 완료: N개 / 진행중: N개 / 대기: N개

📈 프로젝트 현황
  [진행률 80% 이상 → 곧 완료 표시, 10% 이하 → 주의 표시]

💰 매출 현황
  - 누적 총매출: N만원
  - 이번 달 매출: N만원

💡 오늘의 액션 아이템
  [데이터를 분석해서 오늘 당장 처리해야 할 것 3가지 추천]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
