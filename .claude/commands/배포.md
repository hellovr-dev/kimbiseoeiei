아래 순서대로 배포를 진행해줘. 각 단계 결과를 간결하게 보고하고, 오류가 나면 즉시 알려줘.

## STEP 1 — 변경 파일 확인
`git status`와 `git diff --stat`를 실행해서 변경된 파일 목록을 보여줘.
변경 사항이 없으면 "배포할 변경 사항이 없습니다"라고 말하고 중단해줘.

## STEP 2 — 커밋
변경된 파일을 전부 스테이징하고 (`git add -A`),
변경 내용을 한 줄로 요약한 커밋 메시지를 작성해서 커밋해줘.
커밋 메시지 끝에는 항상 아래 줄을 추가해줘:
Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>

## STEP 3 — 푸시
`git push`로 origin main에 푸시해줘.

## STEP 4 — 완료 메시지
아래 형식으로 배포 완료를 알려줘:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🚀 배포 완료!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📦 커밋:  [커밋 해시 7자리]
📝 내용:  [커밋 메시지 요약]
🕐 시각:  [현재 시각]
🔗 저장소: https://github.com/hellovr-dev/kimbiseoeiei
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```
